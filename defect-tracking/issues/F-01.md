### F-01: Stale `onc` → `astp` profile namespace

- **Symptom**: IG renamed its profile namespace
  (`.../guides/onc/us-quality-core/...` → `.../guides/astp/us-quality-core/...`), but
  2,679 fixture files across 12 measures still carried `meta.profile`/extension URLs
  on the old `onc` path, so profile-typed retrieves silently matched nothing.
- **Resolution**: bulk find/replace (original #1; re-applied on the `astp-update` branch
  off UQC main 0866d738, 2026-08-25). +2.28 pts suite-wide expected.
- **Category**: resource / fixture data (bulk-fixed).
- **References**: conversion-notes.md #1; change-classification.md §1.
