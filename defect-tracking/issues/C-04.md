### C-04: CMS1017 fall-prevention HHFI Observation-side authoring mismatch (shared across both engines)

- **Symptom**: 55 failing test cases / 91 mismatched cells. Expected row counts for `Group_1:Denominator Observation` (2/4/6), `Group_1:Numerator Observation` (1/2/etc.), and `Group_1:Measure Observation` (1) are authored in the fixture MeasureReports; both engines return 0 because the fixture Resources don't carry the qualifying data (BMI Observations, AdverseEvent fall entries) the CQL needs to retrieve.
- **Evidence** (`scripts/comparison/engine_shared_issues.py --measure CMS1017FHIRHHFI`):
  * `shared`: 87 cells (both engines return 0 vs expected 2/4/6; identical authoring gap)
  * `cms-only`: 0
  * `qicore-only`: 0
  * `conflicting`: 0
  * `incomplete`: 4 (the `Measure Observation` rows where the engine's TestCaseResult did not produce them due to a missing score-component wiring similar to CMS986)
  * `pass`: 325
  * Overall **shared% of not-passing: 100.0%**.
- **Mechanism**:
  * Case `02d5c5f5`: Denominator Observation exp=2 / act=0, Numerator Observation exp=1 / act=0. The fixture has `Encounter-03632d2d` and `Encounter-391fa73d`, 2 Claims, a `MedicationRequest`, but **no BMI Observations** and no `AdverseEvent: "Inpatient Falls"` resources. The CQL (`input/cql/CMS1017FHIRHHFI.cql` lines 122-129) uses `["USCore.BMIProfile"]` to feed `Risk Variable Body Mass Index (BMI)` -> Denominator Observation; with no Observations in the fixture, the engine correctly returns 0; the MR's expected 2 is an authoring artifact.
  * Case `0884b17b`: same pattern - Denominator Observation exp=4 (act=0), Measure Observation exp=1 (act=None = missing row), Numerator Observation exp=1 (act=0). 2 AdverseEvent resources present but no BMI Observations.
- **Workaround**: none shipped. Candidates: (1) drop orphan Observation-count rows from MeasureReport authoring (silence expected results); (2) drop orphan rows from `expected_results.csv` directly via the same generation step; (3) restore the missing Observations to fixtures to match the authored expectations. **The cleanest path requires a content decision**.
- **Status**: **Confirmed** (2026-09-04, shared% analysis). Not remediated.
