### C-08: CMS142FHIRCommWithDrManagingDiab fixture MR authoring mismatch — RETIRED 2026-09-10, reclassified to E-24

This block is the operational record of the retired C-08 defect. All 5 affected CMS142 test
cases were reclassified to **E-24** (see `defect-tracking/issues/E-24.md`).

- **Original claim**: 5 failing test cases / cells where expected rows carried in fixture
  MeasureReports do not match what the fixtures' resources + CQL / measure resource emit, with
  both engines consistently returning 0 (`shared: 100% of not-passing`).
- **Why this is wrong**: the expected value (1 on `Group_1:Denominator Exception`) is correct,
  and the fixtures DO carry the qualifying CommunicationNotDone data (correct `status`,
  `statusReason` in `"Medical Reason"`, `sent` inside the encounter period, category matching
  the valueset expansion). The fault is that the category-bearing CommunicationNotDone has
  `subject: null`, so the `[CommunicationNotDone: category in ...]` retrieves
  (CMS142 line 155 and siblings) evaluate to `[]` and no Denominator Exception fires — a
  retrieve/attribution gap (likely engine), NOT a MeasureReport authoring mismatch.
- **Reclassification**: `cases.csv` rows for C-08 moved to E-24 (2026-09-10). Catalog rebuilt
  via `scripts/comparison/build_catalog.py`; `known_issues.json` attribution updated
  accordingly.
