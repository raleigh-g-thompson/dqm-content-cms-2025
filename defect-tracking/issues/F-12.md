### F-12: whitespace-corrupted resource `subject.reference` (CMS347 `1d3021bb`)

- **Symptom**: CMS347 `1d3021bb` mismatches 3 cells in Group_3 (Initial Population / Denominator /
  Denominator Exception all expected 1, actual 0). Two resources in the case carry the same
  reference
  `Patient/1d3021bb-b593-4efc-af5b-3  20243bbe9b7` (two stray spaces split the patient GUID
  `320243bbe9b7`):
    1. Encounter `9d311cdd` (CPT 99385 / preventive visit) — engine can neither resolve it to the
       patient nor count it as Qualifying Encounter During Day of Measurement Period.
    2. Observation `ea2c69a6` (LOINC 71007-9 FACIT-Pal screening, `status amended`,
       `valueString pass`, effective 2026-12-31 in MP) — PalliativeCare library's
       "Has Palliative Care in the Measurement Period" predicate
       (`input/cql/PalliativeCare.cql` line 27–31) requires the screening observation to link to
       the patient; with the broken reference the engine drops the observation and the DenEx arm
       never fires.
  CPT 99385 IS in qualifying VS `2.16.840.1.113883.3.464.1003.101.12.1023` (Preventive Care
  Services Initial Office Visit, 18 and Up, via ...101.11.1115 with system
  `http://www.ama-assn.org/go/cpt`) and works in 21 other passing fixtures.
- **Evidence**: both engines agree on the underlying 0/0/0 across the partial re-run after
  repairing only the Encounter (G3 IP/Den 1/1 vs expected, DenEx 1/0) — same family, same
  mechanism, only the broader reference list was incomplete in the first pass.
- **Fix (applied 2026-09-04)**: replace the broken reference with `Patient/1d3021bb-b593-4efc-af5b-320243bbe9b7`
  in every resource in the case carrying the substring via
  `scripts/fix_cms347_fixture_data.py`'s generalized substring replace (idempotent,
  formatting-preserving). CQL and MeasureReport (expected) values unchanged.
- **Category**: resource / fixture data (whitespace-preserved drafting artifact).
- **Status**: fix applied for both resources (Encounter + Observation); engine
  re-verification pending (expected: `1d3021bb` G3 IP/Den/DenEx=1 → resolves all 3 cells).
